1. Inheritance
Inheritance is the process of acquiring the properties and behaviors (variables and methods) of a parent class into a child class.
It promotes code reusability.

Keyword
Java uses the extends keyword.

Example:
class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
}

Here, Dog inherits the eat() method from Animal.

Types of Inheritance

1. Single Inheritance
One child class inherits from one parent class.

A
|
B

Example:

class A {
}

class B extends A {
}

2. Multilevel Inheritance
A child class extends a parent class, and that parent class extends another class.

A
|
B
|
C

Example:

class A {
}

class B extends A {
}

class C extends B {
}

3. Hierarchical Inheritance
Multiple child classes inherit from the same parent class.

    A
   / \
  B   C

Example:

class A {
}

class B extends A {
}

class C extends A {
}

4. Multiple Inheritance
One child class inherits from more than one parent class.

A     B
 \   /
   C

Example (Not Allowed):

class A {
}

class B {
}

// Not possible
class C extends A, B {
}

Why is it not supported in Java (for classes)?
Java does not support multiple inheritance through classes because it can create the Diamond Problem (ambiguity).

Suppose:

class A {
    void display() {
        System.out.println("A");
    }
}

class B extends A {
    void display() {
        System.out.println("B");
    }
}

class C extends A {
    void display() {
        System.out.println("C");
    }
}

If Java allowed:
class D extends B, C
Then when we call:
d.display();

The JVM wouldn't know whether to call display() from B or C. This confusion is called ambiguity (also known as the Diamond Problem).
Therefore, multiple inheritance is not supported for classes in Java.

Note: Java does support multiple inheritance through interfaces


## 🔹 Multiple Inheritance in Java
- **Multiple inheritance** means a class can inherit from more than one parent class.  
- The problem: if both parent classes have a method with the same signature, the child class doesn’t know which one to use → **ambiguity**.  

## 🔹 Scenario (Your Analogy in Code Terms)

- **Two bedrooms** → Two parent classes.  
- **Two laptops of the same brand** → Both parent classes have a method with the same name/signature.  
- **You ask your mom to bring “my laptop”** → The child class calls the method.  
- **Your mom gets confused which laptop to pick** → JVM gets confused which parent’s method to execute.  
- That’s exactly like your mom being confused about which laptop to bring when both look the same.  

---

## 🔹 Example in Java (Why It’s Not Allowed)

class Bedroom1 {
    void laptop() {
        System.out.println("Work laptop");
    }
}

class Bedroom2 {
    void laptop() {
        System.out.println("Personal laptop");
    }
}

// ❌ Java does not allow this
class MyHouse extends Bedroom1, Bedroom2 {
    // Ambiguity: which laptop() should be inherited?
}
